# Cotizador

Sistema de cotizaciones y facturación para PYMES.

## Requisitos

- Python 3.11 o superior

## Instalación

1. Clona el repositorio:

   git clone git@github.com:johnnyllamoja/cotizador.git
   cd cotizador

2. Crea y activa un entorno virtual:

   python -m venv .venv

   - Linux/Mac: source .venv/bin/activate
   - Windows: .venv\Scripts\activate

3. Instala el proyecto en modo editable con dependencias de desarrollo:

   pip install -e ".[dev]"

## Uso

Ejecutar los tests:

    pytest

Ejecutar el linter y formatter:

    ruff check .
    ruff format .
